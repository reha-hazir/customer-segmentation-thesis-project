# **Customer Segmentation Using Unsupervised Clustering**

This project provides a data-driven approach to **segmenting customers** of a grocery store through unsupervised machine learning techniques. By combining **demographic** and **behavioral features**, we identify patterns in customer behavior, enabling targeted and personalized marketing strategies.

## **Problem Statement**

Businesses often fail to leverage their customer data effectively. One-size-fits-all marketing campaigns not only reduce efficiency but also miss key opportunities for personalization. This project addresses the need for more precise customer segmentation, allowing businesses to tailor marketing efforts to specific customer profiles.

---

## **Project Objectives**

- **Apply unsupervised learning** techniques to cluster customers based on both **demographic** and **behavioral attributes**.
- **Compare multiple clustering algorithms** to determine the most effective method for segmentation.
- **Interpret clusters** to uncover consumer profiles and gauge responsiveness to marketing campaigns.

---

## **Methodology Overview**

1. **Data Preprocessing**
   - Encode categorical variables for machine learning algorithms.
   - Detect and treat outliers to ensure clean data.
   - Select and simplify features to reduce noise and enhance model accuracy.

2. **Dimensionality Reduction**
   - **Principal Component Analysis (PCA)** to reduce feature space.
   - Use **Scree plot** to determine the optimal number of components to retain.

3. **Clustering Algorithms**
   - **KMeans Clustering** for partition-based clustering.
   - **Agglomerative Clustering** for hierarchical clustering.
   - Use **Silhouette analysis** to evaluate cluster quality and fit.

4. **Model Comparison**
   - Evaluate clustering performance using silhouette scores and cluster profiling.
   - Compare clustering outcomes to identify the most effective algorithm for segmentation.

---

## **Key Features**

- A comprehensive **pipeline** from raw data preprocessing to actionable customer segmentation insights.
- **Comparative analysis** between KMeans and Agglomerative clustering algorithms to find the best fit.
- **Visualizations** showcasing PCA, cluster boundaries, and customer behavior patterns.
- **Cluster profiling** based on silhouette scores and key demographic/behavioral traits.

---

## **Results**

The analysis identified **3 distinct customer segments**, each representing a unique group with specific behaviors and characteristics:

- **Cluster 0**: Budget-conscious customers who are less responsive to campaigns.
- **Cluster 1**: High-income, educated, single individuals with a strong response to marketing campaigns — the most valuable customer segment.
- **Cluster 2**: Families with moderate spending power and average response rates to campaigns.

- **KMeans** and **Agglomerative Clustering** algorithms for unsupervised learning.
